# Quantum Imperium — Cerchiamo i primi 5 Guardian

**Quantum Imperium** è una Layer-1 blockchain quantum-safe, progettata per essere la **rete di riserva quantistica** dell'ecosistema Ethereum.

Siamo alla ricerca dei **primi 5 Guardian** per formare la rete di sicurezza decentralizzata della chain.

---

## 🛡️ Cosa fa un Guardian

Un Guardian è un membro della rete di sicurezza. Il suo ruolo è **monitorare, verificare e proteggere** la rete, senza avere il potere di modificare lo stato o firmare transazioni arbitrarie.

| **Compito** | **Descrizione** |
| :--- | :--- |
| **Monitoraggio TX** | Osserva le transazioni in mempool e segnala anomalie |
| **Verifica Expiry** | Controlla che le TX rispettino l'expiry (24h) |
| **Rilevazione Anomalie** | Identifica pattern sospetti (gas spike, front-running) |
| **Recovery** | Partecipa al recovery con quorum 2/3 |
| **Bridge** | Firma i messaggi cross-chain (4/7) |

---

## 🚫 Cosa NON fa un Guardian

| **Limite** | **Motivo** |
| :--- | :--- |
| **Non modifica lo stato** | Invariante I5: nessun Guardian può modificare lo State |
| **Non cancella TX arbitrariamente** | Invariante I5 |
| **Non salta nonce** | Invariante I4: nessun nonce può essere riutilizzato |
| **Non firma messaggi arbitrari** | Le sentinelle AI non hanno chiavi private |
