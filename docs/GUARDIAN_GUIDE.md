# Guida per i Guardian di Imperium Chain

## Chi è un Guardian?

Un **Guardian** è un membro della rete di sicurezza decentralizzata di Imperium Chain. Monitora, verifica e protegge la rete, senza potere di modificare lo stato.

## Cosa fa un Guardian

| Compito | Descrizione |
| :--- | :--- |
| Monitoraggio TX | Osserva le transazioni in mempool |
| Verifica Expiry | Controlla che le TX rispettino l'expiry (24h) |
| Rilevazione Anomalie | Identifica pattern sospetti |
| Recovery | Partecipa al recovery con quorum 2/3 |

## Requisiti

- Competenze tecniche (Linux, CLI)
- Impegno: 4+ ore/settimana
- Stake: 1.000 IMP

## Come diventare Guardian

1. Candidatura su Discord
2. Periodo di prova (30 giorni)
3. Nomina a Reviewer
4. Nomina a Guardian

## Ricompense

| Componente | Descrizione |
| :--- | :--- |

| Ricompensa Base | 500 IMP/mese |
| Bonus Performance | 1.000 IMP per vulnerabilità critica |
